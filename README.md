# Bài 1: Khởi tạo Workflow chạy Unit Test tự động cho Java Spring Boot với Gradle

## Giới thiệu
Tài liệu này cung cấp tệp cấu hình GitHub Actions Workflow cho dự án Java Spring Boot sử dụng Gradle.

## Cấu trúc thư mục
- `homework/session_11/ex1/.github/workflows/ci.yml`: Tệp kịch bản CI tự động chạy Unit Test.

## Hướng dẫn sử dụng
1. Đặt tệp `ci.yml` vào đúng đường dẫn `.github/workflows/` trong kho chứa mã nguồn dự án GitHub của bạn.
2. Đẩy (push) mã nguồn lên nhánh `main`.
3. Truy cập tab **Actions** trên GitHub Repository để theo dõi kết quả chạy tự động.
